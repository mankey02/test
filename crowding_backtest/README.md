# 쏠림(Crowding) → 반대 방향 가설 검증

**가설:** 펀딩비가 극단적이고 OI가 급증하면 레버리지가 한쪽으로 쏠린 상태다. 이후 가격은 쏠린 반대 방향으로 움직인다(털어내기).
그리고 그 결과는 매크로 국면에 따라 달라진다.

## 실행

```bash
pip install -r requirements.txt

# 1) 데이터 수집 (Bybit 권장: OI 과거 데이터가 길다. Binance는 OI 최근 30일만 제공)
python fetch_data.py --exchange bybit --symbol BTCUSDT --start 2021-01-01

# 2) 검증
python backtest.py --data data/bybit_BTCUSDT_1h.csv

# 파이프라인 점검: 효과를 심은 가짜 데이터 / 효과가 없는 가짜 데이터
python backtest.py --synthetic
python backtest.py --synthetic --synthetic-effect 0
```

## 신호 정의

| 신호 | 조건 | 가정한 진입 방향 |
|---|---|---|
| `long_crowded` | 펀딩비 과거 90일 대비 상위 10% **그리고** 24h OI 증가율 상위 20% | 숏 |
| `short_crowded` | 펀딩비 하위 10% **그리고** 24h OI 증가율 상위 20% | 롱 |

- 같은 신호는 24시간 안에 한 번만 셉니다(`--cooldown`). 쏠림이 이어지는 동안 표본이 중복되는 것을 막기 위해서입니다.
- 진입은 신호가 확정된 1시간봉의 종가 기준이고, 4h·12h·24h 뒤의 수익률을 봅니다.
- 왕복 비용 0.12%(수수료+슬리피지)를 차감합니다(`--cost`).

## 결과 읽는 법

| 컬럼 | 의미 |
|---|---|
| `mean` / `median` / `win` | 신호대로 진입했을 때의 순수익(bp)과 승률 |
| `base_mean` | **같은 기간·같은 국면**에서 같은 방향으로 무작위 진입했을 때의 평균 |
| `excess` | mean − base_mean. 신호 자체가 만든 초과 성과 |
| `ci_lo`~`ci_hi` | 신호 평균수익의 부트스트랩 95% 신뢰구간 |
| `p_rand` | 무작위 진입 n번의 평균이 신호 평균 이상일 확률(단측). 작을수록 우연이 아님 |
| `period` | `IS`는 분할일 이전(규칙을 만드는 구간), `OOS`는 분할일 이후(검증 구간) |
| `regime` | 전일 종가가 200일선 위면 `bull`, 아래면 `bear` |

### 가설 채택 기준 (권장)
1. `ALL/ALL`에서 `excess > 0`이고 `p_rand < 0.05`, `n ≥ 30`
2. **OOS에서도** 같은 부호, 비슷한 크기로 유지될 것 (가장 중요)
3. `mean`(비용 차감 후 절대 수익)이 0보다 커야 실제로 매매할 수 있음
4. bull과 bear 결과가 다르면 "매크로가 털어내기의 결과를 결정한다"는 가설이 지지됨
   (예: bull 국면의 `short_crowded` 롱은 강하고, `long_crowded` 숏은 약함)

### 주의
- 출력 행이 54개이므로 우연히 `*`가 몇 개 나오는 것은 정상입니다(다중검정). 한두 행만 보고 판단하지 말고 **패턴**을 보세요.
- `--q`, `--oi-q`, `--window-days`를 바꿔가며 IS에서 최적값을 찾았다면, 반드시 OOS로만 최종 판단하세요.
- 펀딩비는 "정산된 값"만 씁니다. 실시간 예측 펀딩비는 과거 기록이 없습니다.
- 200일선은 매크로를 대신하는 단순 지표입니다. 유동성(M2, 스테이블코인 시가총액 증감 등)으로 국면을 직접 정의했다면
  `date,regime` CSV를 만들어 `--macro-csv`로 넘기세요. 이때 그 날짜에 이미 알 수 있었던 값이어야 합니다.

## 주요 옵션

```
--q 0.10            펀딩비 극단 기준
--oi-q 0.20         OI 증가율 상위 기준 (0 = OI 조건 끔)
--window-days 90    백분위 계산용 과거 구간
--horizons 4 12 24  확인할 보유 시간
--cooldown 24       신호 재발생 최소 간격(h)
--cost 0.0012       왕복 비용
--split-date 2024-01-01
--macro-csv FILE    사용자 정의 국면
```

결과는 `results/{이름}_summary.csv`와 `results/{이름}_events.csv`(이벤트별 시각·국면)에 저장됩니다.
